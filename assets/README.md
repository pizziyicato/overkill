# Artwork

Overkill is a Skill Issue Labs project. Its visual identity pairs editorial typography with an illustrated comparison instrument. Several paper paths enter the machine and one checked document leaves it. The instrument is a visual metaphor for the workflow.

## Assets

| Asset | Use |
| --- | --- |
| [overkill-banner.png](overkill-banner.png) | README masthead with the complete illustration and brand lockup |
| [effort-levels.png](effort-levels.png) | Seven effort levels with exact role allocations and the default marked |
| [social-preview.jpg](social-preview.jpg) | A separate composition for repository links and social sharing |

The README embeds the masthead and effort sheet. Set the social preview separately in the repository settings after publication. Adding the image to the repository does not configure GitHub's social preview automatically.

All assets have opaque backgrounds. The effort sheet's full data is also available in the README as a text table. Its counts describe planned roles across a run, with an additional coordinator and batching under host limits. The artwork is not part of the installed skill.

## Visual direction

- Warm ivory `#F4F1E9`, dark ink `#202420` and vermilion `#C94432` form the core palette. Individual raster pixels vary.
- A sturdy editorial serif carries titles. Clear sans-serif text handles labels and numbers.
- The black chassis, paper paths and red selector wheel give the illustration a recognizable silhouette. Material detail belongs to those objects; the surrounding paper stays quiet.
- A branching arrow and dark colophon connect the masthead, reference sheet and social image.
- The effort sheet uses a separate title and illustration rail, aligned numeric columns and a quiet highlight for Medium. Exact labels carry meaning independently of color.

## Provenance

Generated on 4 October 2026 with the built-in image generation tool, then inspected for wording, allocations, clipping and consistency. The earlier masthead and effort sheet were edit inputs. The new masthead supplied the visual reference for the other two assets. The masthead and effort sheet were copied without pixel edits. The social preview was exported to JPEG at its original dimensions, without cropping or retouching. No font files or external illustration assets are needed to display them.

[Impeccable](https://github.com/pbakaus/impeccable) informed the composition and review. [Generation prompts](generation-prompts.md) record the exact instructions used for this revision. These are generated illustrations, not commissioned artwork or hand lettering.
